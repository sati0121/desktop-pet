# Desktop Pet — 桌面宠物

一个运行在 Windows 桌面的小宠物程序（Electron 实现）：宠物在桌面上行走、点击互动、可拖动，支持自定义形象与气泡字幕。
灵感来自一个朋友---感谢ningning...

## 功能

| 操作 | 效果 |
|---|---|
| **单击宠物** | 随机播放一个可爱动作（跳跃、转圈、摇摆、弹跳、跳舞等），并随机显示一条气泡字幕 |
| **按住拖动宠物** | 在活动区域内自由移动，松手后从该处继续随机散步 |
| **右键宠物** | 菜单：切换形象、字幕管理、调整活动区域、更换形象、退出 |
| **字幕管理** | 修改、添加、删除气泡字幕（即时保存并生效） |
| **调整活动区域** | 绿色虚线框：拖动边框/角手柄缩放，拖动内部整体移动，`Esc` 或点 `✓` 保存 |
| **更换形象** | 从本地选择透明背景 PNG 作为新宠物形象 |

## 快速开始

### 环境要求

- Windows 10/11
- 已安装 [Electron](https://electronjs.org)（或使用任意已存在的 Electron 运行时）

### 启动

1. 将本仓库目录作为 Electron 应用根目录。
2. 准备宠物形象（见下文「形象准备」）。
3. 用 Electron 加载本目录启动：

   ```bash
   electron .
   ```

> 提示：`run.bat` 是作者本机环境的启动脚本，其中 Electron 路径为本地绝对路径，直接使用时需修改为你的 Electron 位置。

## 形象准备

> ⚠️ **本仓库不包含任何形象图片**，需由使用者自行准备。

宠物形象为**透明背景（含 alpha 通道）的 PNG 图片**，要求：

- 格式：PNG，带透明背景
- 建议：人物主体尽量完整、边缘清晰，方便抠图与缩放
- 数量：可以准备多张，作为不同的可切换形象

### 放置方式

1. 将透明 PNG 放入目录：`src/renderer/assets/sprites/`
2. 在 `src/main.js` 的 `SPRITES` 数组中注册：

   ```js
   const SPRITES = [
     { id: 'sprite1', name: '我的形象1', path: 'src/renderer/assets/sprites/sprite1.png' },
     // ...
   ];
   ```

   右键宠物 → 形象 即可切换。

3. 程序启动默认使用 `SPRITES` 第一项作为初始形象。

### 从照片制作透明 PNG

仓库提供了基于 [rembg](https://github.com/danielgatis/rembg) 的自动抠图脚本：

```bash
pip install rembg onnxruntime    # 安装 AI 抠图依赖
python tools/prep_sprite.py <源图片路径>    # 抠出单张透明 PNG
```

- 脚本输出到 `src/renderer/assets/sprites/` 并自动裁剪、缩放。
- 若 rembg 不可用，脚本会自动回退为 flood-fill 色键抠图（背景较简单时可用）。
- 抠图后建议人工检查边缘，必要时手动清理残留。

## 活动区域

- 默认：屏幕右上角，约占屏幕面积 **1/6**（宽 1/3 × 高 1/2）。
- 区域设置在运行后通过右键菜单调整，保存于 `%APPDATA%\desktop-pet\config.json`，下次启动自动恢复。

## 字幕气泡

- 点击宠物时有概率显示一条气泡字幕。
- 默认字幕为若干常见短语；通过右键菜单「字幕管理…」可增删改，即时生效。
- 字幕保存在 `config.json` 的 `subtitles` 数组；全部删除时会回退到默认列表。

## 技术实现

- **宠物窗口**：无边框、透明、置顶、跳过任务栏；窗口随宠物移动。
- **随机游走**：主进程驱动平滑步进（smoothstep），朝左移动时镜像翻转，带随机停顿。
- **点击 vs 拖动**：位移超过 6 像素判定为拖动，否则为点击动作。
- **区域编辑**：自绘 8 个缩放手柄 + `setBounds()` 缩放（规避 Windows 透明窗口原生缩放不可靠的问题）。
- **多窗口架构**：宠物窗口 + 区域编辑窗口 + 字幕管理窗口，通过 IPC 通信。
